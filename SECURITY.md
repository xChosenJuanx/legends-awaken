# Security Policy

Legends Awaken is currently an early-stage project.

## Reporting a vulnerability

Please avoid publishing sensitive exploit details in a public issue before the maintainer has had a reasonable opportunity to review them.

For non-sensitive security improvements, a normal GitHub issue is appropriate. For potentially exploitable vulnerabilities, contact the maintainer privately through an available GitHub contact method and include:

- A description of the issue
- Affected component
- Reproduction steps or proof of concept, when safe
- Potential impact
- Suggested mitigation, if known

## Scope

Security review currently focuses on original, redistributable project code and development workflows. Third-party proprietary material is not intended to be part of this open-source repository.
