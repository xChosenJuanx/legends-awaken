LEGENDS AWAKEN — KNIGHT 3D BUILD 2
This build uses the supplied d_kn Priston Tale files directly:
- dkn.inx animation index
- dkn.smd model
- dkn.smb skeleton/animation data
- supplied BMP/TGA textures

Upload EVERYTHING in this ZIP to the ROOT of the legends-awaken GitHub repository.
Important: keep the pt-assets folder and its subfolders exactly as-is.

Controls:
WASD / Arrows = move
Shift = run
Space = attack
1 = cycle animation
Mouse drag = rotate camera
Mobile = joystick + buttons

This is the first live integration pass. If the loading screen reports a PT loader error,
send a screenshot of the browser Console so the exact legacy asset-path/format issue can be patched.
