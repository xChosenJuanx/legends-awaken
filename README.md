# Legends Awaken

Legends Awaken is an independently developed MMORPG project focused on learning, prototyping, and documenting practical game-development systems.

## Project status

**Early development / experimental.** The project is under active development and its structure, APIs, and gameplay systems may change as implementation progresses.

## Goals

- Build and document reusable MMORPG gameplay concepts.
- Experiment with character movement, animation, combat, UI, and related systems.
- Improve maintainability through testing, debugging, and clear documentation.
- Keep the project's original code and documentation accessible for learning and collaboration.

## Development

Development currently consists of iterative prototypes and test builds. Work is being done in small, testable steps so technical problems can be isolated before larger systems are integrated.

Recent work has included character/skeleton and animation diagnostics, pose and binding experiments, and controlled test builds.

## Getting started

Build and setup instructions are still being documented while the project is in early development. A reproducible setup guide will be added as the project stabilizes.

## Contributing

The project is currently in early development. Issues, technical feedback, documentation improvements, and focused contributions are welcome as the repository becomes easier to build and test independently.

Please avoid submitting third-party proprietary game code, assets, trademarks, or other material that you do not have permission to redistribute.

## Open-source scope

The intention of this repository is to share original project code and documentation that can legally be redistributed. Third-party proprietary game assets or source code are not intended to be part of the open-source project.
