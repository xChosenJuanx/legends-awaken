# Contributing to Legends Awaken

Thanks for your interest in Legends Awaken.

The project is in early development, so focused contributions are preferred.

## Helpful contributions

- Bug reports with reproducible steps
- Documentation corrections and improvements
- Small, focused code changes
- Tests and debugging improvements
- Suggestions for original MMORPG systems and developer tooling

## Before contributing

1. Check existing issues before opening a duplicate.
2. Keep changes focused on one problem or feature.
3. Explain what changed and how it was tested.
4. Do not submit credentials, secrets, generated binaries, or unrelated files.
5. Do not submit proprietary third-party source code, game assets, trademarks, or other material you do not have permission to redistribute.

## Licensing note

The repository's licensing and redistributable scope are still being reviewed. A project-wide open-source license will only be added after the maintainer has verified that the covered material can legally be licensed and redistributed.
